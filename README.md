# Python Text Analyzer & Contact Manager

Two lightweight command-line Python utilities built using the Python standard library.

## Features

### Text Analyzer
- Counts characters with and without spaces
- Counts words and sentences
- Finds the longest word
- Identifies the most frequent word(s)

Run:
```bash
python text_analyzer.py
```

### Contact Manager
- Add and view contacts
- Search by first or last name
- Edit or delete contacts by ID
- Basic phone-number validation when adding contacts

Run:
```bash
python contact_manager.py
```

## Requirements
Python 3. No external packages required.

## Notes
Contacts are stored in memory and are lost when the program exits. The utilities do not use API keys or external services.
